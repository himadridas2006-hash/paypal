## Brand & Style

This design system establishes an institutional-grade, high-velocity interface for autonomous financial agents, programmatic guardrails, and consumer-accessible payment pipelines. The visual philosophy resolves the tension between mechanical, algorithmic rigor and approachable fiduciary safety.

### Aesthetic Direction: Modern Fintech & Elevated Precision
The interface executes an architectural, light-first canvas defined by mathematical clarity, ultra-crisp borders, and focused chromatic energy. It combines high-end wealth management composure with immediate consumer legibility:
- **Calibrated Restraint:** Flat, optical-white cards rest on subtle cool-slate backing tiers to establish hierarchy without dense or heavy ornamentation.
- **Electric Telemetry:** Kinetic accents and primary focus targets use concentrated, pure-spectrum electric blues to signal machine activity, verified consensus, and active payment rails.
- **Algorithmic Legibility:** High-density financial figures, tabular metrics, guardrail limits, and audit logs sit within crisp grids framed by subtle boundaries and balanced spatial intervals.
- **Fiduciary Assurance:** The emotional signature is calm authority—every automated operation, authorization threshold, and status review provides explicit visual confirmation and friction-free overrides.

## Colors

The palette balances structural neutrals, high-integrity semantic signals, and vivid focal accents.

### Palette Architecture
- **Primary (`#3B82F6`):** Electric Blue acts as the direct interactive anchor for actions, active focus rings, key transactional states, and platform triggers.
- **Secondary (`#4F46E5`):** Deep Vibrant Indigo provides depth across multi-agent workflows, contextual indicators, and directional accents.
- **Tertiary (`#10B981`):** Emerald verifies safe execution thresholds, approved mandates, cleared liquidity, and validated guardrails.
- **Neutral (`#0F172A`):** Deep Slate serves as the foundation for dense financial copy, data headers, and structural hierarchy.

### Canvas & Surface Structure
- **Base Canvas:** `#F8FAFC` provides an ultra-soft cool slate field that reduces optical glare during continuous oversight sessions.
- **Elevated Surfaces:** `#FFFFFF` defines card layers, modular data nodes, modal drawers, and transactional sheets.
- **Border Gradients & Lines:** `#E2E8F0` and `#EDF2F7` deliver hairline framing (1px) around actionable and segregated data blocks.

### Semantic Status Matrix
- **Approved / Verified:** `#10B981` (Surface Tint: `#ECFDF5`, Border: `#A7F3D0`).
- **Escalated / Needs Review:** `#F59E0B` (Surface Tint: `#FFFBEB`, Border: `#FDE68A`).
- **Blocked / Hard Limit Tripped:** `#EF4444` (Surface Tint: `#FEF2F2`, Border: `#FECACA`).
- **Agent Intelligence / Automation:** `#6366F1` (Surface Tint: `#EEF2FF`, Border: `#C7D2FE`).
- **Sandbox Environment:** Distinctive diagonal-neutral or amber-tinted badge structure for uncommitted mock testing.

## Typography

Typography pairs geometric structure with high-legibility execution across continuous text and dense numeric summaries.

### Font Roles
- **Headlines (Manrope):** Geometric structure, balanced counters, and contemporary cutouts deliver authority to balance summaries, mandate headings, and system alerts.
- **Body & Controls (Hanken Grotesk):** Neutral, crisp humanist grotesque optimized for high-speed scanning of complex policy terms, prompt executions, and status chips.
- **Tabular Figures:** All numeric displays (balances, gas limits, velocity metrics, ISO 4217 currency units) strictly apply font-variant numeric tabular figures (`tnum`) and zero-slashing flags (`cv01`/`zero`) to prevent horizontal jitter during live telemetry updates.

## Layout & Spacing

The spatial architecture organizes multi-agent execution feeds, security boundary maps, and transactional pipelines into clear, structured views.

### Grid System
- **Desktop (>= 1280px):** 12-column fluid grid. Content maximum bounding width of `1440px`. Column gutters hold at `1.5rem` (`24px`), with canvas outer margins at `2rem` (`32px`).
- **Tablet (768px - 1279px):** 8-column layout. Structural side rails compress into an overlay or icon-dock. Column gutters scale to `1.25rem` (`20px`).
- **Mobile (< 768px):** 4-column layout. Margins reduce to `1rem` (`16px`). Dashboard cards reflow into a singular vertical timeline with horizontal tab groups.

### Spatial Rhythms
Component padding operates strictly on a predictable 8px/4px rhythm:
- Micro gaps (`space-xs` = 4px, `space-sm` = 8px) govern inline chip metadata, icon-to-label offsets, and badge internal padding.
- Component structural gaps (`space-md` = 16px, `space-lg` = 24px) establish distance between input groups, list row dividers, and control groups.
- Block gaps (`space-xl` = 32px) delineate standalone mandate clusters, checkout configurations, and audit telemetry blocks.

## Elevation & Depth

Visual hierarchy uses flat, high-clarity surface separation accented by diffuse, light-refracting ambient depth. Rather than heavy, muddy shadows, surfaces rely on crisp perimeter borders paired with multi-tiered luminance.

### Depth Hierarchy
- **Level 0 (Field):** Flat `#F8FAFC`. Houses background canvas textures and contextual section anchors.
- **Level 1 (Card / Resting Surface):** `#FFFFFF` paired with an outline of `1px solid #E2E8F0` and an ambient shadow: `0 1px 3px 0 rgba(15, 23, 42, 0.04), 0 1px 2px -1px rgba(15, 23, 42, 0.02)`.
- **Level 2 (Active Focus / Floating Element):** Hovered mandate blocks, sliding panels, and active card segments use an augmented shadow: `0 10px 15px -3px rgba(15, 23, 42, 0.06), 0 4px 6px -4px rgba(15, 23, 42, 0.03)` with border tint shift toward `#CBD5E1`.
- **Level 3 (Modals, Checkout Sheets & System Guardrail Alerts):** Elevated overlays float against an optical scrim (`rgba(15, 23, 42, 0.4)` backdrop blur of `4px`), using a drop shadow of `0 20px 25px -5px rgba(15, 23, 42, 0.1), 0 8px 10px -6px rgba(15, 23, 42, 0.04)`.

## Shapes

The geometric framework balances human-centered consumer trust with the clean technical posture of modern web applications.

### Curvature Geometry
- Level 2 defines a base corner radius of `0.5rem` (`8px`) across interactive components (inputs, list items, small buttons).
- Large content wrappers, modal containers, and metric cards scale directly to `rounded-lg` (`1rem` / `16px`), matching the 16px border-radius standard for all core system surfaces.
- Micro tags, pill badges, guardrail counters, and payment rail indicators make use of fully circular bounds (`9999px`) to distinguish categorical indicators from actionable cards.

## Components

### Buttons & Interactive Triggers
- **Primary Action:** Solid Electric Blue (`#3B82F6`) background, white (`#FFFFFF`) label, `8px` corner radius, font weight 600. On hover, background shifts to `#2563EB` with a `0 2px 4px rgba(59, 130, 246, 0.2)` shadow.
- **Secondary Action:** Crisp white (`#FFFFFF`) background, `1px solid #E2E8F0`, neutral text (`#0F172A`). On hover, background transitions to `#F8FAFC`.
- **Rail Action (PayPal Integration):** High-contrast checkout button featuring brand-standard deep navy/gold styling, or cleanly encapsulated inside standard card borders for zero brand fragmentation.

### Status Pills & Indicators
- Built on full-radius pill silhouettes (`rounded-full`) with a height of `24px` or `28px`.
- Composed of an icon indicator, a `6px` solid status dot, and an uppercase/semitransparent label (`label-sm`).
- **Approved:** Tinted `#ECFDF5` container, `#059669` text, `#10B981` dot.
- **Review / Escalated:** Tinted `#FFFBEB` container, `#D97706` text, `#F59E0B` dot.
- **Blocked / Rule Broken:** Tinted `#FEF2F2` container, `#DC2626` text, `#EF4444` dot.

### Cards & Mandate Enclosures
- Standardised with a `16px` border-radius (`rounded-lg`), `1px solid #E2E8F0`, and `#FFFFFF` background.
- Padding inside cards is locked to `1.5rem` (`24px`).
- Header structures within cards divide layout metadata and actions with an explicit `1px solid #EDF2F7` horizontal separator.

### Progress Usage Rings & Guardrail Trackers
- Circular and horizontal indicators feature high-contrast tracks (`#E2E8F0`) with dynamic SVG stroke caps (`round`).
- Safe execution zone displays in `#10B981`; usage exceeding 80% shifts automatically to `#F59E0B`; hard stop threshold displays in `#EF4444`.

### Input Fields & Verification Controls
- Height: `44px` on desktop, `48px` on touch displays. Border radius: `8px`.
- Default: `1px solid #CBD5E1` on `#FFFFFF`.
- Focus State: Unambiguous 2px outline using `#3B82F6` with an additional `0 0 0 3px rgba(59, 130, 246, 0.15)` focus ring.

### Lists & Ledger Transactions
- Divided with thin `1px solid #EDF2F7` border rules.
- Row hover states smoothly blend into `#F8FAFC`.
- All monetary amounts align strictly to the right edge with `font-variant-numeric: tabular-nums` to ensure exact decimal alignment across thousands of entries.

### Sandbox Testing Badge
- Striated corner pill or ribbon using `#F59E0B` background with `#78350F` monospace label: `TESTNET // SANDBOX ACTIVE`. Visible across all platform headers to maintain absolute operational context.
